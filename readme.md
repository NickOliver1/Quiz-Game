# Quiz Game
## Readme 
By Nick Oliver

## Purpose
I designed this project using multiple AI agents and did some code editing myself. It is a simple 3-question quiz game, with a built-in timer. The purpose of this project was to help me gain a better understanding of the fundamentals of web development (how HTML and JavaScript interact, using the DOM, aria-live attributes, etc). 

## Installation Instructions
To play this game, you **need not** install anything on your computer. All you need is a web browser. To get going, please follow the steps below: 

1. Doownload both index.html and script.js and save them in the same folder on your computer. 

2. Launch index.html. 

3. Enjoy and have fun!
